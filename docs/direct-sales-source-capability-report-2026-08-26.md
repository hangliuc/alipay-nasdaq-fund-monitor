## 1. 审计范围

- 审计时间：2026-08-26（Asia/Shanghai）
- 配置文件：`config.json`
- 基金数量：37 只
- 基金管理人：24 家
- 网络行为：只读访问官网公开页面/API；不登录、不提交交易、不绕过验证码、设备签名或认证。

本报告把数据源分为两类：

1. **实时交易 API**：请求返回当前基金交易状态或限额字段，并且能识别直销/网上直销渠道。
2. **官网当前产品页/状态页**：页面直接展示当前交易状态或直销限额，但不是交易 API。

公告 PDF、历史限额表、产品目录脚本单独列出，不计入上述两类的“当前产品页交易状态”。

## 6. 结论与使用建议

1. **实时 API 生产优先级**：易方达 > 宝盈。易方达可直接采信“网上直销”行；宝盈应把 session 超时单独标记为“官方接口需认证”。
2. **当前产品页状态可直接展示**：国泰、华安、华夏、国富、富国、博时、南方，共 10 只基金。
3. **南方已完成前端接口适配**：不能把静态页面表头当成基金状态；应读取官方交易状态 API，并保存 `currentDate`、状态原文和观察时间。
4. **公告/PDF/限额表不能冒充实时 API**：即使本次能成功解析，也必须保存公告日期、页面更新时间和抓取时间。
5. **任何 API 空结果、会话超时或页面未返回基金行，都应记录为“未获取/需认证”，不得沿用旧限额值冒充当前值。**
