# 数据来源说明

## 日报卡片的数据来源框架

日报卡片只使用天天基金数据。限购字段依次采用 `JJJZ → 天天基金详情页 → 本地上次记录 → 未知/失败`；近 1 年收益率采用 `RANKING → 天天基金详情页 → 空值`（收益率不使用历史值）。

| 数据 | 正常来源 | 降级与最终结果 |
|---|---|---|
| 限购状态、限购额度、净值 | 天天基金 JJJZ 全市场接口 | 详情页 → `data/history.json` 同分组 `latest` → `未知/失败` |
| 近 1 年收益率 | 天天基金 RANKING 全市场接口 | 详情页 → 空值 |
| HTML 降级 | 天天基金单基金详情页 | 页面也无法解析限购时才读取本地历史 |
| 本地历史 | 上次成功/上次运行快照 | 输出 `source=stale`、低置信度和数据陈旧告警 |
