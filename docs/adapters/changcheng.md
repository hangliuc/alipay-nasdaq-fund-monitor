# 长城基金（Changcheng）官方 Adapter

## 适配器状态

| 项目 | 内容 |
|---|---|
| 管理人 | 长城基金管理有限公司（长城） |
| 代码模块 | `fund_monitor.fetch.direct_sales.adapters.changcheng.ChangchengAdapter` |
| 公开目录 | [长城基金产品页](https://www.ccfund.com.cn/main/jjcp/index.shtml) |
| 产品页模板 | `https://www.ccfund.com.cn/main/jjcp/cache/{code}.shtml` |
| 公告接口 | `https://www.ccfund.com.cn/fund/querycatdatajj.do`（官网产品页前端的临时公告查询接口） |
| 公告目录 | `catalogid=998`，按 `fundcode` 查询 |
| 直销渠道口径 | 长城基金官网展示的直销平台、长城基金 APP/微信公众号和直销中心 |
| 当前认证边界 | 目录、产品页和直销机构信息可匿名访问；公告列表由官网前端加密请求加载，不绕过加密、验证码或登录 |
| 第三方来源 | 不使用 |

## 可获取字段

### 基金目录

| 标准字段 | 官网位置/字段 | 说明 |
|---|---|---|
| `code` | 产品行 `.desc`、产品链接 `/main/jjcp/cache/{code}.shtml` | 六位基金/份额代码 |
| `name` | 产品行 `.name` | 官网当前基金简称 |
| `fund_type` | 产品行首个 `td[jjlx]` 的 `jjlx` 属性 | 官网原始基金类型码，保留原始值 |
| `share_class` | 名称末尾 A/B/C/D/E/F/Y | 份额类别 |
| `source_url` | 产品行链接 | 长城官网产品页 |
| `risk_level` | 目录风险列 | 例如 `R4 中高风险`，保留原始文本于目录快照 |
| `nav` | 目录单位净值列 | 保留原始文本于目录快照 |
| `nav_date` | 目录净值日期列 | 统一为 `YYYY-MM-DD` |
| `trade_status` | 目录最后交易状态列 | 例如“正常”“暂停申购”“暂停运作” |

### 产品页快照

| 标准字段 | 官网位置/字段 | 说明 |
|---|---|---|
| `name` | `.fund_title .fund_name` | 官网基金简称 |
| `full_name` | 概况表“基金全称” | 官网完整名称 |
| `fund_type` | 概况表“基金类型”或产品标签 | 例如 QDII |
| `risk_level` | 产品标签或概况表“风险等级” | 例如 R4 中高风险 |
| `inception_date` | 概况表“成立日期”/“基金合同生效日” | 标准日期 |
| `asset_scale` | 概况表“基金规模” | 官网原始文本；部分产品页不公开 |
| `net_value_date` | 产品页净值栏 | 标准日期 |
| `trade_status` | 产品页交易状态字段 | 未公开时明确写“官网产品页未公开当前交易状态” |
| `fields` | 概况表全部键值、净值和直销平台字段 | 保留原始字段，不丢弃公司特有字段 |

### 直销限额与公告

| 标准字段 | 解析来源 | 说明 |
|---|---|---|
| `direct_sales_limit` | 长城官网本次成功解析的最新公告 PDF | 金额统一为人民币元，如 `500元`；无当前公告时为 `null` |
| `direct_sales_status` | 公告正文 | `ok`；暂停或恢复分别输出 `暂停`/`不限` |
| `quota_type` | 公告正文 | 通常为单日单个基金账户累计申购及定期定额投资 |
| `quota_remark` | 公告正文和解析规则 | 标记是否明确写出直销渠道、是否为份额代码表格 |
| `announcement_title` | 公告列表 | 公告标题 |
| `announcement_date` | 公告列表 | 公告发布日期，统一为 `YYYY-MM-DD` |
| `source_url` | 公告附件 URL | 长城官方 PDF；不写入东方财富等第三方链接 |
| `raw` | 产品字段和公告文本 | 保留产品字段、公告标题、公告日期及正文快照 |

## 获取流程

1. 访问长城官网基金产品页，解析所有 `/main/jjcp/cache/{六位代码}.shtml`，得到当前全量目录。
2. 对单只基金访问其官网产品页，解析概况表、标签、净值和公开直销机构信息。
3. 从官网产品页前端使用的 `querycatdatajj.do` 查询临时公告（目录 `998`），只筛选标题含“调整/暂停/恢复”及“大额申购/定投”的记录。
4. 按公告日期倒序下载官方附件 PDF，优先解析公告明确的“直销渠道”金额，其次按公告中的份额代码与金额列对齐。
5. 若公告接口因官网前端加密、频率限制或网络原因没有返回当前公告，输出 `official_api_no_data`；不使用旧硬编码值、不猜测“不限”。

## 认证和频率边界

| 场景 | 处理 |
|---|---|
| 产品目录/产品页匿名可访问 | 正常抓取 |
| 公告接口要求官网前端加密 | 不绕过；记录当前接口边界并返回无数据 |
| 401/403 或验证码/登录 | 输出 `official_interface_requires_auth`，不提交认证 |
| 公告 PDF 返回限流页 | 不解析为公告；下一次运行重试 |
| 交易购买页 | 不访问、不提交订单、不要求开户 |

## 单元测试

对应测试文件为 `tests/test_changcheng_adapter.py`，覆盖目录解析、产品字段、公告 HTML/JSON 过滤、金额/暂停/恢复解析、无数据不复用旧值和认证边界。

## 直销获取结论（统一判定）

- `config.json` 目标：**未获取直销限额**——`018036` 产品页可访问，但本次公告接口未返回可确认的当前限额，Adapter 返回 `official_api_no_data`。
- 只有本 Adapter 本次解析出的长城官网当前公告/状态才写入“已获取”；公告接口无结果、限流、认证或网络失败均为“未获取/需认证”，不能以此前 `500元` 核验值替代。
- 失败时不回填统一兼容层、历史静态值或第三方平台数据。
