# QDII 直销 / 代销额度卡片设计规范

> 用途：生成小红书竖版卡片，分别呈现 QDII 主动型基金和被动型基金的近一年收益率、直销额度、代销额度。
>
> 当前已确认方案：方案 C 字体 + 开放式表头（无表头卡片）。

## 输出要求

- 输出两张卡片：主动型一张、被动型一张。
- 画布固定为 `1080 × 1440 px`，PNG，竖版。
- 文件标题必须分别为：
  - `QDII 主动型基金直销 / 代销额度`
  - `QDII 被动型基金直销 / 代销额度`
- 不输出序号列、底部注释、单基金方块卡片或基金行之间的大间距。
- 卡片需在表格内容区域叠加低透明度斜向 `HRunning` 水印；水印横跨中部，裁切或转发后仍应可见，但不得影响数值阅读。

## 数据规则

### 数据源与字段

- 基金池和展示名称来自 `config.json`。
- 卡片展示四列，顺序固定：
  1. 基金名称（后接基金代码）
  2. 近一年收益率
  3. 直销额度
  4. 代销额度
- 直销额度只接受基金公司官网当前可验证结果。
- 代销额度沿用现有行情/代销抓取逻辑。

### 筛选与排序

- `direct_sales_status != "ok"` 的基金不进入卡片。
- 未实现直销额度获取的基金在抓取前直接排除：`016702`、`017093`、`018036`、`019442`。
- 同一类别内按 `return_1y` 从高到低排序；收益率相同按基金代码升序。
- 最终纳入、抓取后跳过和抓取前排除的基金代码必须写入 manifest，确保可追溯。

### 文本与状态

- 基金名过长时省略；基金代码紧随名称显示为次级文字。
- 额度使用紧凑格式，例如 `1万`。
- `暂停`：红色。
- 其他直销/代销额度：浅金色。
- 正收益：红色，并固定显示为小数点后两位（例如 `86.00%`），保证四位数字一致。
- 负收益或缺失：金色或 `—`；不使用绿色。

## 版式

### 标题区

- 四角使用金色 L 形细线：距离边缘约 `40 px`，边长 `56 px`。
- 英文眉题：`y=112`，居中。
  - 主动型：`ACTIVE QDII · RETURN & QUOTA`
  - 被动型：`PASSIVE QDII · RETURN & QUOTA`
- 主标题：`y=156`，居中，中文宋体常规字重、`52 px`。
  - 不要额外加粗主标题。
- 日期：`y=228`，居中，格式 `YYYY — MM — DD`。
- 日期下方短金线：`x=480..600`，`y=282`。

### 表头与数据区

- 表头起点：`y=330`。
- 表头必须为开放式文字行，**禁止**圆角深色底卡片。
- 表头下方只保留一条金色细线：`x=76..1004`，`y=374`。
- 四列锚点：

| 列 | x 坐标 | 对齐 |
| --- | ---: | --- |
| 基金名称 | `82` | 左对齐 |
| 近一年收益率 | `620` | 右对齐 |
| 直销额度 | `840` | 右对齐 |
| 代销额度 | `998` | 右对齐 |

- 数据行高度：`60 px`。
- 行间仅使用低透明度细分隔线。
- 基金之间必须连续排列，不得添加独立卡片、方块容器或较大行间距。
- 页面底部居中增加免责声明：`免责声明：数据仅供参考，不构成投资建议；额度以基金公司及销售机构实时规则为准`。

## 实现位置
